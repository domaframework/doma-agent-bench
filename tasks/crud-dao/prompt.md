Add data access for the `employee` table to this application using Doma.
The schema is in `db/schema.sql`.

Create the following:

1. An entity class `bench.entity.Employee` mapped to the `employee` table.
   - It is a mutable class with a public no-arg constructor and getters/setters
     (`getId`/`setId`, `getName`/`setName`, `getSalary`/`setSalary`,
     `getDepartmentId`/`setDepartmentId`, `getVersion`/`setVersion`).
   - `id` is `Integer` and is generated by the database (identity column).
   - `salary` is `java.math.BigDecimal`, `departmentId` and `version` are `Integer`.
   - `version` is used for optimistic locking.
2. A DAO interface `bench.dao.EmployeeDao` with these methods:
   - `Employee selectById(Integer id)` — returns `null` when not found
   - `List<Employee> selectAll()` — all employees ordered by `id`
   - `int insert(Employee employee)` — sets the generated id on the entity
   - `int update(Employee employee)` — fails with an optimistic lock error if the version is stale
   - `int delete(Employee employee)`
